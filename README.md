# 🏥 Hospital Emergency Room Dashboard

An interactive Excel dashboard built to track and report on hospital ER performance — patient volume, wait times, satisfaction, and admissions — with month-by-month and year-over-year comparisons.

## 🛠️ Tools Used
- Microsoft Excel (Pivot Tables, Slicers, Power Query, Dashboard Design)

## 📊 What the Dashboard Covers
- **Patient volume** trends by month
- **Average wait time** tracking
- **Patient satisfaction score**
- **Admission rate**: 57% on-time vs. 43% delayed
- **Gender-wise distribution** of patients
- **Age-group breakdown**
- **Department-wise referrals**
- Slicers for **month-by-month** and **year-over-year (2023 vs. 2024)** comparison

## 🔍 Process
1. Cleaned raw hospital ER data (handled missing values, standardized formats, removed duplicates)
2. Built pivot tables to summarize volume, wait time, satisfaction, and admissions
3. Designed an interactive dashboard layout with slicers for dynamic filtering
4. Added visualizations for gender, age-group, and department-level breakdowns

## 📈 Key Insight
Admission rates skew toward on-time processing (57%) but delays (43%) remain significant enough to flag for operational review — useful for identifying bottlenecks in patient intake.
